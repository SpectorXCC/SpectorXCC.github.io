# Hugo 博客课程报告填写提纲

本文件仅提供写作提纲，不是完成版报告。请使用自己的操作、截图和结果；若用 Word 编写，优先在老师提供的报告模板中填写。最终提交 PDF，而不是直接把这个文件当作已经完成的实验报告。

## 封面

填写姓名、学院、专业、班级、学号和二寸电子照片。报告序号以老师表格为准。

## 一 实验目的与环境

说明要完成 Hugo 博客、本机到宿主机访问、GitHub Pages 外网托管。填写真实的宿主机系统、虚拟机软件、Linux 版本、网络模式、Hugo 版本、Git 版本及虚拟机 IP。

## 二 环境安装与站点创建

写明实际安装方法，附 `hugo version`、`hugo new site`、主题子模块安装的截图。解释配置文件、内容目录、主题目录和生成目录的作用。

## 三 配置与页面实现

展示核心配置片段：PaperMod、首页 HTML/RSS/JSON 输出、六个菜单。说明首页简介、关于页真实信息与照片、三篇文章、分类标签、归档和搜索如何实现，并展示关键页面。

## 四 宿主机访问验证

写明虚拟机网卡模式和 IP、启动命令，以及宿主机浏览器访问过程。附地址栏包含虚拟机 IP 的首页及子页面截图。说明遇到的网络问题和解决步骤。

## 五 GitHub Pages 部署

填写自己的仓库 URL 与公网 URL。解释为什么不把 `public/` 放进源码主分支、子模块为什么需要递归拉取，以及工作流的主要步骤。附仓库、工作流、绿色运行记录、Pages 设置与公网访问截图。

## 六 问题与解决

选取自己真实遇到的问题，逐项说明现象、检查方法、原因、修改和复测结果。没有遇到某问题时，不应把模板中的常见问题写成亲身经历。

## 七 总结

说明你现在理解了哪些 Linux、Git 和静态站点知识，哪些操作仍需改进。可写后续准备添加的真实内容与功能。

## 提交检查

确认使用自己的信息、截图和网址；图片有图号图注；总页数不超过 30 页；命名为 `序号-学号-姓名.pdf`。具体格式和评分逐项查看 `COURSE-CHECKLIST.md`。
